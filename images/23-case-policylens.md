# Image brief — Ch 23 Case: PolicyLens

**Filename:** `images/23-case-policylens.jpg`
**Aspect:** 16:9 hero, Kindle-readable.

**Subject:** A two-tier verification pipeline visualized as gates. Tier 1: four deterministic rule boxes (Similarity Threshold / Numeric Match / Causal Scrutiny / Entity Consistency) processing a fan of extracted claims, most of them passing through to colored verdicts (green Supported, yellow Partially Supported, orange Unsupported, red High-Risk Silent Failure). Tier 2: an "Agent" box (Claude tool-calling) that only fires on the orange and red flagged claims — visually a smaller, more selective layer. A small annotation: "0 API calls for Supported / Partially Supported verdicts."

**Mood:** Forensic, careful, audit-trail-heavy. The visual story is cost-aware adjudication.

**Negative space:** Top for chapter title; bottom for the deterministic-vs-agent ratio annotation.

**Notes:** The teaching image is *the cheap rules clear most claims; the expensive agent fires only when the rules already worried.* Avoid government-document clichés. Schematic over decorative.
