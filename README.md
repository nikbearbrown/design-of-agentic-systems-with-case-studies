# Design of Agentic Systems with Case Studies

## About the book

This 2026 rough manuscript is for software students and developers comparing agentic system designs. Learn to place decisions, retrieval, tools and review steps deliberately, then use case studies to make trade-offs explicit. A reader should be able to explain why a pattern fits a particular workflow and identify evidence needed before using it. Familiarity with application workflows helps; cases are not evidence of clinical, legal, financial or security effectiveness.

## How to teach or study it

Start with design patterns and evidence boundaries, then read at least two contrasting cases. For each, draw a workflow, label the human decision, and describe a failure test that can disagree with the system. Use the [two authored exercise blocks](exercises/design-of-agentic-systems-with-case-studies-exercises.md) and Chapter 14’s project sequence as practice. The older eleven-chapter restructuring notes do not establish a course adoption or a finished edition.
